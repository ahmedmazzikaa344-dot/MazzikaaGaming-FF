MAZZIKAA GAMING FF — نسخة واجهة متجر مجانية
================================================
الملفات:
- index.html: صفحة المتجر العربية المتجاوبة.

التشغيل:
1) افتح index.html في متصفح لمعاينة الموقع.
2) للنشر المجاني: ارفع index.html إلى مستودع GitHub ثم فعّل GitHub Pages من Settings > Pages (Deploy from a branch، branch main، folder /root).
3) استخدم رابط GitHub Pages الناتج.

مهم جدًا:
- هذه نسخة واجهة أمامية. لا توجد قاعدة بيانات أو لوحة إدارة فعلية أو تسجيل دخول أو تخزين إيصالات.
- نموذج الطلب ينشئ رقمًا مرجعيًا محليًا ويرسل بيانات الطلب برسالة واتساب؛ لا يحتفظ النظام بالطلبات على خادم ولا يؤكد الدفع تلقائيًا.
- صورة الإيصال لا تُرفع تلقائيًا؛ العميل يرسلها بنفسه في واتساب.
- لا تضع أسرارًا أو كلمات مرور في ملفات الواجهة.
- الأسعار وأرقام الدفع مضمنة حسب المعلومات التي قدمها صاحب المتجر؛ تحقق منها قبل النشر.
